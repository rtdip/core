The 2025 AMOS project on **RTDIP Timeseries Forecasting** represents a comprehensive effort to design, develop, and contribute open-source forecasting components for the RTDIP platform. Built by a dedicated student team, this collaboration brings advanced trend analysis, anomaly detection, and predictive modeling capabilities to real-time data pipelines.

<!-- more -->

## About This Project

This AMOS 2025 Winter Semester project focuses on extending RTDIP with enterprise-grade forecasting capabilities. The team is researching and implementing forecasting techniques using Python and Apache Spark, validating them with real-world datasets from industry partners, and ensuring they meet RTDIP's modular, tested, and well-documented standards.

### Project Vision

To empower organizations with open-source, scalable, and transparent forecasting capabilities that enable data-driven decision-making across industries. By extending RTDIP with advanced forecasting and anomaly detection components, the vision is a future where time series insights—trends, seasonality, and predictive patterns—are seamlessly integrated into real-time data pipelines.

## Key Focus Areas

### Models & Algorithms
- Advanced time series forecasting methods
- Anomaly detection approaches
- Time series decomposition techniques
- Model training and optimization
- Performance evaluation on real datasets

### Data & Preprocessing
- Dataset research and validation
- Shell dataset preprocessing and decomposition
- SCADA dataset preparation
- EIA refinery yield data processing
- 3W (Petrobras) dataset integration
- Data ingestion from Azure Blob Storage

### Architecture & Development
- Modular Spark-based component design
- Integration with RTDIP pipeline framework
- Build and deployment documentation
- Production-ready implementation standards

### Fundamentals
- Time series forecasting theory and methods
- Machine learning libraries for forecasting
- High-performance computing (HPC) optimization
