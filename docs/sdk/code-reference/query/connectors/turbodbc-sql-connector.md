# TURBODBC SQL Connector (Deprecated)

!!! warning "Deprecation Notice"
    **TURBODBC is no longer inherently supported in RTDIP (as of v0.14.4).** This connector is maintained for backward compatibility only.
    
    If you require turbodbc connectivity, you have two options:
    
    1. **Use an older RTDIP version:** Install an RTDIP version prior to v0.14.4 which includes turbodbc support
    2. **Manual Installation:** Manually install turbodbc or earlier into your current RTDIP setup
    
    For new projects, consider using the [Databricks SQL Connector](db-sql-connector.md) or [PYODBC SQL Connector](pyodbc-sql-connector.md) instead.
